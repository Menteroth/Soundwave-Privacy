# Soundwave Privacy Policy

**Last updated: September 8, 2026**

## 1. Overview

Soundwave is a Discord bot built on Red-DiscordBot and operated by an independent bot owner. Soundwave uses Discord-provided information and data stored by its loaded extensions to provide its features.

This Privacy Policy explains what types of information Soundwave may store or process, why that information is needed, and how users can request deletion of data associated with them.

Soundwave is self-hosted and its configuration and loaded third-party extensions are controlled by the bot owner.

## 2. Information Soundwave May Store

Depending on which features a user interacts with, Soundwave may store some of the following information:

- Discord User IDs
- Discord Guild, Channel, Role, and Message IDs
- User preferences and settings
- User-created content submitted to certain bot features
- Attachments submitted to certain features
- Reminders, tasks, timers, and other user-created entries
- Birthdays and time zone information
- Game-related statistics, experience, levels, scores, inventories, or similar progress
- Message counts and certain activity statistics
- Voice-channel activity used for statistics or leveling features
- Information relating to roles assigned or scheduled for users
- Information relating to reactions, starred messages, or other Discord messages used by certain features
- Event participation and event-creation information
- Giveaway creation and participation information
- Information relating to virtual stocks or other game-related transactions
- Other information necessary for individual bot features to function

The exact information stored depends on which commands and features a user uses.

Soundwave's core Red-DiscordBot functionality also stores certain Discord identifiers and information necessary for the bot to function.

## 3. Why Information Is Stored

Information may be stored for purposes including:

- Providing requested bot features
- Remembering user preferences and settings
- Maintaining user-created content
- Tracking game or feature progress
- Scheduling reminders, timers, events, or other actions
- Maintaining statistics and leaderboards
- Assigning or restoring Discord roles
- Preventing abuse or maintaining feature-related blocklists
- Maintaining information necessary for moderation or other server functionality
- Allowing features to continue functioning between bot restarts

Soundwave does not require users to provide personal information such as their real name, postal address, or telephone number in order to use the bot.

## 4. Third-Party Extensions

Soundwave uses third-party Red-DiscordBot extensions ("cogs") in addition to Red's core functionality.

These extensions may store additional information required for their individual features. The data handled by a particular extension depends on how that extension is implemented and how it is used.

Red-DiscordBot provides information about third-party extension data handling through its End User Data Statement system.

Users can use the following commands in Soundwave to view information about stored data:

`+mydata whatdata`

`+mydata 3rdparty`

The Red-DiscordBot data statement is also available here:

https://docs.discord.red/en/stable/red_core_data_statement.html

## 5. External Services

Some Soundwave features may communicate user-provided information to external services when the relevant feature is used.

For example, translation functionality may send the text or other information necessary for a translation request to an external translation service.

Soundwave does not send information to external services merely because a user is present on a server. External processing occurs only where required by a feature being used.

## 6. Data Retention

Information is generally retained for as long as it is required for the associated feature to function.

Some information is automatically removed when it is no longer needed, such as certain reminders after they have been triggered.

Other information may remain stored until it is manually removed, the relevant feature is removed, or the bot's stored data is otherwise deleted.

Retention periods therefore vary depending on the feature and the type of information involved.

## 7. Requesting Deletion

Users can request Soundwave to remove data associated with their Discord account using Red-DiscordBot's data deletion functionality:

`+mydata forgetme`

The ability to remove data depends on the individual extension. Extensions that implement Red's user-data deletion system can remove the data associated with the requesting user.

Some data may not be attributable to a particular user, may be required for server functionality, or may be retained in operational logs or other systems where deletion is not automatically supported.

If a user believes that information associated with them remains after using the deletion command, they may contact the bot owner.

## 8. Data Access

Soundwave does not provide users with a general database interface.

Red-DiscordBot provides the following commands for information about stored user data:

`+mydata whatdata`

`+mydata 3rdparty`

The `getmydata` functionality provided by Red-DiscordBot is currently not available in Soundwave.

## 9. Data Sharing

Soundwave does not intentionally sell user data.

Information may be transmitted to external services when required by a specific feature, such as translation or other functionality that relies on an external service.

Third-party Red-DiscordBot extensions may have their own data-handling behavior. Users should consult the End User Data Statements provided by those extensions for more specific information.

## 10. Security

Reasonable measures are used to restrict access to Soundwave's stored data. However, no computer system or storage method can be guaranteed to be completely secure.

Access to Soundwave's stored data is limited to the bot owner and systems required to operate the bot.

## 11. Changes to This Policy

This Privacy Policy may be updated when Soundwave's configuration, loaded extensions, or data-handling practices change.

The "Last updated" date at the beginning of this policy indicates when the policy was most recently reviewed.
